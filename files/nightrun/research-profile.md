# Research profile

Tune this file to guide idea discovery. The default is intentionally neutral.

- Prefer problems with a clearly identifiable user and testable demand.
- Prefer prototypes that can be evaluated in days rather than months.
- State assumptions, competing options, expected costs, and disconfirming
  evidence.
- Use public sources and cite links in the research artifact.
- Do not use private repository or account data unless the operator explicitly
  includes it in the task.
- Do not purchase services, register domains, contact people, or publish content
  during research.
