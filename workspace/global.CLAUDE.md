# Global workspace rules

- Lead with the result and keep updates concise.
- Read repository instructions before editing.
- Work on branches and use pull requests unless the operator explicitly asks
  for another workflow.
- Run relevant tests before claiming completion. State what was not tested.
- Ask before destructive operations, production deployment, or force-pushing.
- Never read, print, modify, or commit files under `/etc/nightshift/secrets`.
- Never place credentials in command arguments, logs, source files, or reports.
